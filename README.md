# NIGHT.LOG

原生 HTML、CSS、JavaScript 实现的赛博朋克风格个人博客与交互作品。

这是去除个人素材的公开源码版本：不包含个人肖像、摄影照片、城市背景截图、开发截图、PDF、Sites 配置或旧 Git 历史。使用程序化背景和抽象身份标记，相册路由显示空态。

## 本地运行

需要 Node.js 20 或更新版本，无第三方运行依赖。

```sh
node serve.cjs
```

打开 http://127.0.0.1:4173/ 。静态发布目录为 dist。

## 功能

- 首页、日志搜索与收藏、个人档案、本地留言和终端。
- 可跳过的全屏过场；支持减少或关闭动态效果。
- 跑酷射击小游戏：七种武器、两种首领、换弹、限时浮台、冲刺、每五关强化和本地成绩。
- 键盘钢琴：17个琴键、自由弹奏、新手跟弹和三首公版旋律简谱。
- 设置与数据保存在当前浏览器，留言不上传。

## 检查

```sh
node --test tests/*.test.cjs
node scripts/check.cjs
```
